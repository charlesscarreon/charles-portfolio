# Personal Website SEO Audit

## Stage 2 — Name Search and Discoverability Audit

**Website:** https://charlescarreon.vercel.app/  
**Scope:** Name-based discoverability and identity differentiation  
**Out of scope:** Technical SEO implementation and website ranking guarantees

---

## Executive Summary

The main issue is not whether the website or its owner can be found online.

The main challenge is **identity ambiguity**: multiple people share the name **Charles Carreon**, so the name alone does not always uniquely identify one person.

The strongest strategy is to build and consistently reinforce a distinct professional identity associated with:

> **Charles Carreon + Computer Science + Software Development + Philippines**

The full name **Charles Serrano Carreon** currently provides significantly stronger differentiation.

---

# 1. Search: `Charles Carreon`

## Finding

The name **Charles Carreon** is ambiguous because multiple people share it, including individuals with larger or older public online footprints.

The personal website is discoverable, but the name alone does not uniquely identify its owner.

## Recommended Action

Do not focus solely on making every search result for the name refer to one person.

Instead, strengthen a distinctive professional identity around the name.

Recommended identity associations:

- Computer Science
- Software development
- Philippines
- C#
- Game development

---

# 2. Search: `Charles Serrano Carreon`

## Finding

The full name provides significantly stronger differentiation and is strongly connected to the personal website.

## Recommended Action

Continue using **Charles Serrano Carreon** as the canonical full professional name.

This should remain the primary name used for formal and identity-focused website information.

---

# 3. Search: `Charles S. Carreon`

## Finding

The abbreviated name variation is also connected to the same public identity.

## Recommended Action

Explicitly connect this name variation with the canonical full name and shorter name through structured identity information.

Recommended name relationship:

```text
Charles Serrano Carreon
        ├── Charles Carreon
        └── Charles S. Carreon
```

---

# 4. Searches with Professional Context

Examples:

- `Charles Carreon developer`
- `Charles Carreon Computer Science`

## Finding

Adding professional context makes it significantly easier to distinguish the intended person from other people with the same name.

## Recommended Action

Continue strengthening the connection between the name and relevant professional fields:

- Computer Science
- Software development
- C#
- Game development
- Related future projects

Use these associations naturally in website content and public professional profiles.

Avoid keyword stuffing or repeating descriptors unnaturally.

---

# 5. Main Identity Disambiguators

## Finding

The strongest current characteristics separating this professional identity from other people with the same name are:

- Computer Science
- Philippines
- Software development
- C#
- Game development

## Recommended Action

Use these identifiers consistently where appropriate across:

- Personal website
- GitHub
- LinkedIn
- Project documentation
- Competition or event profiles
- Other intentionally public professional profiles

Consistency is more valuable than repeatedly changing the professional description.

---

# 6. External Identity Signals

## Finding

The personal website provides the strongest central source for the professional identity.

External profiles and references can strengthen the connection between the name and the website.

## Recommended Action

Review major public professional profiles and ensure that they:

1. Use a consistent name.
2. Accurately describe the same professional identity.
3. Link to the personal website where appropriate.

The goal is to establish a connected identity network:

```text
Personal Website
       ↕
     GitHub
       ↕
    LinkedIn
       ↕
Projects / Events
```

Only connect profiles that are intentionally part of the desired public identity.

---

# 7. Project-Based Discoverability

## Finding

Projects can create distinctive search associations that may be more unique than the name alone.

Over time, work and projects can become additional ways for people to discover the same professional identity.

## Recommended Action

Publish meaningful information about major projects.

When a project has sufficient content, consider creating a dedicated page.

Potential future search associations include:

- Charles Carreon C#
- Charles Carreon Unity
- Charles Carreon game development
- Charles Carreon gesture recognition

The goal is not to target these phrases artificially. The goal is to create genuine content that naturally connects the name with the work.

---

# Stage 2 Overall Assessment

## Main Finding

The main problem is **not discoverability**.

The person and website can already be found online.

The main challenge is **name ambiguity**.

A useful representation of the desired identity path is:

```text
Charles Carreon
      ↓
Computer Science
      ↓
Software Development
      ↓
Philippines
      ↓
Personal Website and Professional Identity
```

---

# Final Conclusion

The full name **Charles Serrano Carreon** is already significantly more distinctive than the shorter name **Charles Carreon**.

The shorter name becomes much easier to identify correctly when professional context is added.

The long-term goal should not be to make every search for:

> **Charles Carreon**

refer exclusively to one person.

The more realistic and valuable goal is to strengthen the association:

> **Charles Carreon + Computer Science + Software Development + Philippines = this specific professional identity**

This creates a distinct and recognizable identity without requiring the name itself to be unique.
